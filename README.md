# Overview


The name "Wonder Game" was inspired by the musician Stevie Wonder, referencing both his cultural impact and his representation as a visually impaired artist.
The project was developed and presented during the **42nd PROJETE**, the traditional technology and project exhibition organized by **ETE FMC (Escola Técnica de Eletrônica Francisco Moreira da Costa)**.

The system was designed to provide an accessible gaming experience through audio interaction and tactile controls, allowing users to answer questions without relying on visual interfaces.

The gameplay consists of listening to questions through headphones and answering them using directional buttons. The main objective is to score as many points as possible by answering correctly.

This repository is preserved as a **legacy educational project**, documenting one of our early experiences with embedded systems development, accessibility-focused design, and collaborative engineering projects.

---

# Features

- Audio-based interaction
- Physical button controls
- Quiz gameplay with score system
- Headphone audio output (P2 connector)
- Accessible interaction model for visually impaired users
- Low-cost embedded prototype

---

# Hardware Components

The prototype includes:

- Display module
- Push buttons
- P2 audio connector
- Embedded processing platform
- Virtual prototype developed in TinkerCAD

> The display was included due to project requirements, although the primary interaction method is audio-based.
